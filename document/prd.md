Project Title:
 Personalized Digital Cognitive Support System for Individuals Experiencing Dementia
Problem:
Individuals experiencing dementia may face difficulties with memory, attention, medication management, and completing everyday routines. Existing digital tools often address these needs separately rather than providing an integrated and personalized system.
Proposed Solution:
develop a prototype digital platform that combines cognitive exercises, personalized reminders, daily routines, and caregiver monitoring. The system will track user interactions and cognitive-task performance to personalize activities and provide information about changes in performance over time.
Target Users:
Individuals experiencing mild cognitive impairment or early-stage dementia and their caregivers.
Core Features:
**Cognitive-training games
Adaptive difficulty
Medication reminders
Detection optional
Daily schedule
Simple check-ins
Cognitive-performanc–e tracking:
reaction time
accuracy
number of attempts
memory recall
attention-task performances
consistency between sessions
Caregiver dashboard
Personalized activities
Memory Journal
Potential Technologies:
Mobile/web application
Database for user information and activity history
Data visualization
Machine learning/adaptive algorithm
Accessibility-focused UI/UX
Main Outcome:
 A functional prototype demonstrating how technology could support cognitive stimulation and everyday independence while providing caregivers with useful information about user activity.
